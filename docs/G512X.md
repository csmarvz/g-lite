# G512 X 75

USB 046D:C35F, wired, 2025, 75% with 81 keys, two knobs above the navigation column (brightness and volume), a light bar along the front and TMR (magnetic) switches with adjustable actuation. It speaks HID++ 2.0 at index 0xFF.

G-Lite opens it on the keyboard screen with live lighting only, like the G915 (`Keyboards.G512X`). It has 0x8101 like the G515, so G-Lite claims the lighting the same way: 0x8101 fn 6 `05` (host mode), then 0x8071 fn 5. Its key map (`app/models/g512-x-75.json`) is built from a review and the USB key codes, not checked on a real keyboard yet.

## What the report shows

- Features: 0x8071 v6 (RGB effects), 0x8081 (per-key lighting), 0x8040 (brightness), 0x8101 (onboard files), 0x4540 (layout, 01 on the reported keyboard), like the G515, plus features G-Lite doesn't know (0x00D0, 0x1B05, 0x1B08, 0x1B20, 0x8051, 0x4523, 0x00C3, 0x8061, 0x1602).
- 0x8071 has two clusters:
  - Cluster 0, the keys: 0x00 Off, 0x01 Static, 0x0A Breathe, 0x15 Cycle, 0x16 Wave, 0x17 Ripple, then 0x18 (unknown, parameters `00 0D 07 D0`). Effects 0 to 5 have the same parameter bytes as on the G515.
  - Cluster 1, probably the light bar: the same without Ripple. G-Lite sends Static there when Ripple is picked.
- 0x8081 lit ids: 0x00–0x6F, 0xA0–0xC0 and 0xF2–0xFE. The ids past 0x6F aren't keys G-Lite knows (maybe the light bar).

## Why it doesn't save yet

Its onboard files aren't laid out like the G515's:

- The directory entries (0x0000, 0x0100) start `04 01 81 01 40 6F` and end `02`, where the G515's start `01 01 81 01 40 63` and end `FF`. Byte 9 is the profile's size: 0x6F (111 bytes) here, 0x63 (99) on the G515.
- The factory profile (0x0101) has one more byte at position 2 (`03`), so the idle times and the light records sit one byte later than on the G515: the records start at 31, the flags at 75.
- The user directory (0x0000) points to file 8 with the same CRC as the factory profile, so 0x0008 is a copy of it. The report asked for 99 bytes and got error 04; reports now read the size the directory gives.

Before Save: a report with the full 111-byte files, then the meaning of byte 2 and of the 12 bytes past 99.
