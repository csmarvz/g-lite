# K295 Silent Wireless Keyboard

M/N Y-R0042, on its nano receiver (USB 046D:C534, listed as Unifying). Not a G device, but it speaks HID++ 2.0 at index 1, so G-Lite lists it by its wireless id (4023, `Devices.Others`) with its battery, on the info page, with one setting: F1–F12 as media keys. Checked on a real keyboard.

It calls itself "Wireless Keyboard" (0x0005). G-Lite shows it as "K270/K295": the keyboard of the MK270 set reports the same wireless id, name, firmware (RQK 49.00 build 0029) and features ([Solaar issue #1408](https://github.com/pwr-Solaar/Solaar/issues/1408), Solaar's `descriptors.py` names 4023 "Wireless Keyboard MK270"), so G-Lite can't tell them apart. Y-R0042 is also the M/N on Logitech's K345 page, but no K345 has been seen reporting 4023. Logitech's K295 page gives Y-R0015, so the K295 seems to have been built on more than one module.

## What the report shows

- 0x1000 battery: only two levels: 30 means good and 5 means low (fn 0 gave `1E 05`: 30%, next level 5%). `Found.Coarse` shows a full icon for 30 and the low icon for 5, without a percentage, and the info page says Good or Low. Reports keep the number.
- 0x40A0: Fn inversion. fn 0 reads it, fn 1 sets it (byte 0). Checked on a K295, which has no Fn key: at 00 (the default) F1–F12 send F1–F12; at 01 they send media actions, and the separate media keys don't change. G-Lite shows it on the info page as "Use F1–F12 as media keys" (`Found.MediaKeys`), keeps it as `fnswap.<device>` in `settings.txt` and sends it again after each scan that finds the keyboard, in case it forgot it.
- 0x1B00 (reprogrammable keys, version 0), 0x4100 (encryption), 0x4520 (keyboard layout), 0x1D4B (wireless status).
