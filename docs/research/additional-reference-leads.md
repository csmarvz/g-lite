## How to promote a lead into the map

Read the license and actual device/protocol source; locate hardware logs or captures; record the exact commit, model IDs, report selectors and feature versions; distinguish implemented behavior from TODOs and README aspirations. A test fake with a hardcoded feature table is not a hardware capture. Do not run packaged executables or unreviewed capture scripts just to inspect a project.
