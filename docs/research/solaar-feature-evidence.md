Extracted from checked-in `docs/devices` reports on 2026-11-08. See [snapshot](snapshots.md). These are historical owner captures at particular firmware versions, not an exhaustive supported-device list. Only product/transport facts and feature IDs are retained here; serial numbers, unit IDs, local paths and friendly names are deliberately omitted. A feature absent from this extracted table is not proof of hardware absence if the report is partial.

Transport IDs come from each report's labeled `Transport IDs` mapping. Filename IDs are only labels and are not independently classified as USB IDs. A question mark means that an older report did not print a feature version. Feature versions are important: `8071v2` and `8071v4` can behave differently.

## Consequences for the map

- G502 X PLUS 4099 has 2201v2, 8060v0, 8071v2, 8081v2 and 8100 in its report. Existing notes suggesting that the entire G502 X family likely needs 8061 should not be promoted to a capability claim.
- G515 LIGHTSPEED TKL report labels WPID 40B4, USB C355 and Bluetooth B389. The wired-only G515 TKL C358 in logirgb is a distinct transport/product row.
- The G915 report whose filename ends 407E actually labels its WPID **407C** in the contents. Do not add 407E from the filename.
- Solaar includes a G600 diagnostic capture, but its static descriptor explicitly comments that G600 is not HID++. A dump file is not proof of successful protocol support.
- The G213 report filename says C366 while the descriptor and OpenRGB use C336. The capture contents explicitly say USB C336, so the filename is a typo; use C336.
